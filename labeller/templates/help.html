📚 NestScope Help & Documentation

Comprehensive guide to using the NestScope avian monitoring platform

What is NestScope?

NestScope is an AI-powered platform for Gulf Coast avian monitoring and analytics. It combines natural language processing, computer vision, and traditional database management to provide a complete toolkit for analyzing bird colony data from 2010-2021.

The platform covers five states (Texas, Louisiana, Mississippi, Alabama, and Florida) and includes data from hundreds of colonies and thousands of observations.

Platform Components

🦅 Core Modules

  • NestChat - Natural language interface for querying bird data with AI-generated SQL
  • NestVision - AI-powered bird detection and counting in aerial imagery
  • NestDB - Database management interface with Git-based version control
  • Nestperts - Expert annotation platform for training data creation
  • FloodWatch - Multi-modal flood hazard monitoring and coastal risk analysis

🎯 Key Features

  • Ask questions in plain English and get instant visualizations
  • Upload colony images for automatic bird detection and species classification
  • View and edit database records with full version control
  • Create expert-labeled datasets for model training with Swift AI
  • Export data and images for external analysis in multiple formats

Quick Start Workflow

For Data Analysis

  1. Open NestChat from the main app (port 8501)
  2. Ask a question like "How many birds were observed in Texas in 2020?"
  3. Review the generated SQL query and results
  4. Explore interactive charts and maps
  5. Download results as CSV if needed

For Image Analysis

  1. Open NestVision from the main app
  2. Upload a colony image (JPEG, PNG, or TIFF)
  3. Choose detection mode: Swift (fast) or Apex (accurate)
  4. Click "Run Detection" and wait for results
  5. Review detections and species breakdown with color-coded boxes
  6. Download annotated images or send to Nestperts for refinement

For Database Management

  1. Navigate to NestDB at http://localhost:5000/nestdb
  2. Browse tables in the Table Browser tab
  3. Toggle Edit Mode to modify records
  4. Changes are automatically versioned with Git
  5. Use Version History to view or rollback changes

Dataset Overview

The NestScope database contains comprehensive Gulf Coast bird colony survey data:

  • Time Period: 2010-2021 (12 years of surveys)
  • Geographic Coverage: Texas, Louisiana, Mississippi, Alabama, Florida
  • Primary Species: 20+ seabird and wading bird species
  • Observation Types: Bird counts, nest counts, colony locations
  • Data Sources: Aerial surveys, ground surveys, photo documentation
💡 Tip: The main count data is in tblColonyTotals2010-2021_MayJuneCombined. This table contains pre-aggregated bird and nest counts for each colony, year, and species.

NestChat - Natural Language Data Interface

Ask questions in plain English and get instant answers with visualizations. NestChat uses AI to convert your questions into SQL queries and generate insights.

How It Works

  1. You ask a question in natural language
  2. AI generates SQL based on database schema
  3. Query executes against SQLite database
  4. AI analyzes results and generates natural language answer
  5. Visualizations appear (charts, maps) based on data type
ℹ️ Under the Hood: NestChat uses an enhanced metadata system that helps the AI understand the difference between bird counts (observations) and photo records, ensuring accurate responses.

Example Questions

Population & Trends

  • "How many Brown Pelicans were observed in 2020?"
  • "Show me the trend of Royal Tern populations from 2010 to 2021"
  • "Which species had the biggest population increase?"
  • "What were the total bird observations by year?"

Geographic Queries

  • "List all colonies in Louisiana"
  • "Which state has the most bird colonies?"
  • "Show me colony locations on a map"
  • "What colonies are between latitude 29 and 30?"

Species-Specific

  • "Where do Black Skimmers nest?"
  • "Show me all observations of Reddish Egrets"
  • "Which colonies have both pelicans and terns?"
  • "Compare nest counts vs bird counts for Royal Terns"
💡 Pro Tip: Be specific about whether you want bird counts or nest counts. For example: "How many Royal Tern NESTS were counted in 2020?"

Understanding Visualizations

NestChat automatically chooses the best visualization:

  • Line Charts: Time-series data (trends over years)
  • Bar Charts: Comparisons (top colonies, species rankings)
  • Maps: Geographic data (colony locations with coordinates)
  • Tables: Detailed records and multi-column results

Interactive Features

  • Hover: See exact values on charts
  • Zoom: Click and drag to zoom into regions
  • Pan: Move around on maps
  • Download: Export charts as PNG or data as CSV

NestVision - AI Bird Detection & Counting

Upload colony images and use computer vision to automatically detect and count birds with species classification.

Detection Modes

🚀 Swift Mode (Default)
  • Speed: ~3x faster than Apex
  • Accuracy: Excellent for most images
  • Use Case: Quick previews, real-time processing
  • Model: swift.onnx (9.6 MB)
🎯 Apex Mode
  • Speed: Slower but more thorough
  • Accuracy: Best for small or distant birds
  • Use Case: Final analysis, expert annotation
  • Model: apex.onnx (37 MB)
ℹ️ SAHI Processing: For large images (>1024px), NestVision automatically uses SAHI (Slicing Aided Hyper Inference) which slices the image into overlapping tiles for better detection of small birds.

🔬 SuperZoom Mode: Press Shift+S to use 512x512 slices instead of 1024x1024 for detecting extremely small or distant birds. Slower but more accurate for tiny targets.

Species Classification

NestVision classifies detected birds into 7 species groups with color-coded bounding boxes:

  • COLOR_WADER (Pink): Roseate Spoonbills, Reddish Egrets
  • DARK (Dark Gray): Cormorants
  • GULL (Light Gray): Laughing Gulls, other gulls
  • PELICAN (Tan): Brown Pelicans, White Pelicans
  • SHOREBIRD (Gold): Black Skimmers, Oystercatchers
  • TERN (White): Royal Terns, Sandwich Terns, Least Terns
  • WHITE_WADER (Off-White): Great Egrets, Snowy Egrets, White Ibis
⚠️ Note: Classification is at the group level, not individual species. For precise species identification, use Nestperts for expert annotation.

Step-by-Step Workflow

  1. Upload Image: Click "Browse files" or drag and drop (JPEG, PNG, TIFF supported, max 200MB)
  2. Choose Mode: Select Swift (fast) or Apex (accurate)
  3. Adjust Threshold: Default 0.25 works for most images (lower = more detections)
  4. Run Detection: Click button and wait 10-60 seconds
  5. Review Results: See total count, species breakdown chart, and annotated image
  6. Export or Refine: Download image or send to Nestperts for expert correction
💡 Pro Tip: If you get too many false detections, increase the confidence threshold to 0.35-0.45. If birds are being missed, decrease it to 0.15-0.20.

Best Practices

Image Quality

  • Resolution: Higher resolution = better detection
  • Lighting: Well-lit images work best
  • Contrast: Birds should contrast with background
  • Focus: Sharp images perform better than blurry

Camera Angle

  • Overhead: Best for accurate counts
  • Oblique: Works but may miss overlapping birds
  • Ground-level: Challenging, consider manual counting

NestDB - Database Management Interface

Supabase-inspired interface for viewing, editing, and managing bird survey data with full Git-based version control.

Accessing NestDB

Navigate to: http://localhost:5000/nestdb

Or click "NestDB" in the Expert Tools section of the sidebar in the main app.

Table Browser

Viewing Tables

  1. Select a table from the dropdown
  2. Data loads automatically (50 rows per page by default)
  3. Use pagination controls to navigate pages
  4. Adjust "Rows per page" for more/fewer results

Edit Mode

  • View Mode (Default): Read-only display
  • Edit Mode (Toggle ON): Click cells to edit values

Editing Data

  1. Toggle Edit Mode ON
  2. Click any cell to edit (except primary keys marked with 🔑)
  3. Make changes to values
  4. Click "Save Changes" button
  5. Changes are automatically versioned (Git commit created)
⚠️ Important: Primary key columns (marked with 🔑) cannot be edited. They are set automatically or must be unique.

SQL Query Editor

Execute custom SQL queries for advanced data exploration:

Writing Queries

  • Use standard SQLite syntax
  • SELECT statements recommended (read-only by default)
  • Supports JOINs, subqueries, CTEs, aggregations
  • Comments allowed (-- single line, /* multi-line */)

Query History

  • Last 10 queries saved automatically
  • Click "Reuse" to load a previous query
  • Click "Remove" to delete from history
💡 Pro Tip: Copy queries from NestChat's SQL display and paste them here for modification and re-execution.

Version History (Git-Based)

All database changes are tracked with Git version control:

Automatic Versioning

  • Every save creates a Git commit
  • Commit includes SQL dump of entire database
  • Timestamp and author recorded
  • Full audit trail maintained

Creating Manual Checkpoints

  1. Enter your email (saved for future use)
  2. Type a checkpoint description (e.g., "Before bulk species update")
  3. Click "Save Checkpoint"
  4. Checkpoint appears in commit timeline

Rolling Back

  1. Expand the commit you want to restore
  2. Click "Rollback Here" button
  3. Read the warning carefully (undoes all changes after that commit)
  4. Click "Confirm Rollback"
  5. Database restored to that state
  6. Safety snapshot created automatically
⚠️ Rollback Warning: Rolling back will undo ALL changes made after that commit. A safety snapshot is created, but use this feature carefully. Consider creating a manual checkpoint first.

Nestperts - Expert Species Training Platform

Create expert-labeled datasets for training species classification models. Uses Swift AI for interactive segmentation and supports multi-expert workflows.

What is Nestperts?

  • Refining AI detections from NestVision
  • Creating ground-truth training datasets
  • Species-level identification (not just groups)
  • Multi-expert collaboration and validation

Accessing Nestperts

Navigate to: http://localhost:5000

Or click "Nestperts" in the Expert Tools section of the main app sidebar.

Annotation Workflow

  1. Select Image: Click thumbnail in gallery
  2. Review Existing Detections: Check if all birds are detected
  3. Add Missing Birds:
    • Press S for AI Tool
    • Click on center of undetected bird
    • AI Tool detects the bird and creates a box
    • Assign species from dropdown
  4. Delete False Positives:
    • Click incorrect detection box
    • Press Delete key
  5. Correct Species Labels:
    • Click on detection box
    • Change species in dropdown
    • Click "Update" to save
  6. Save Annotations:
    • Press Enter or click "Save"
    • Labels saved in YOLO format
    • Species metadata saved separately

Swift AI Segmentation

How It Works

  1. You click on a bird
  2. Swift AI processes the image around that point
  3. Generates a segmentation mask
  4. Bounding box calculated from mask
  5. 5% padding added for better coverage

Two Detection Modes

  • Fast Mode: 720x720 resolution, faster processing
  • SAHI Mode: 1024x1024 resolution, better accuracy for small birds
💡 Tips: Click near the center of the bird. Avoid clicking on overlap between birds. Use SAHI mode for small or distant birds.

Common Issues & Solutions

Page Won't Load

Solutions:

  • Check that all services are running: ./run_app.sh
  • Verify URLs: Main app (8501), Nestperts/NestDB (5000), API (8000)
  • Try hard refresh: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)
  • Check logs: tail -f logs/server.log

"Backend Connection Failed"

Solutions:

  • Check backend health: curl http://localhost:8000/health
  • View logs: tail -f logs/server.log
  • Restart services: ./run_app.sh
  • Verify port 8000 is not blocked by firewall

NestChat "Query Failed"

Solutions:

  • Rephrase question more clearly and specifically
  • Check that table/column names exist in schema
  • Review generated SQL for errors
  • Verify OPENROUTER_API_KEY in .env file

NestVision Upload Fails

Solutions:

  • Check file size (max 200 MB)
  • Verify format (JPEG, PNG, or TIFF only)
  • Try renaming file (remove special characters)
  • Check available disk space

NestDB Changes Won't Save

Solutions:

  • Verify Edit Mode is toggled ON
  • Check you're not editing primary key columns
  • Ensure data type matches column type
  • Check logs for validation errors

Swift AI Segmentation Fails

Solutions:

  • Verify models/mobile_sam.pt exists
  • Try clicking center of bird more precisely
  • Switch between Fast and SAHI modes
  • Restart Nestperts to clear cache

Frequently Asked Questions

Can I use NestScope offline?

Answer: Partially. NestVision works offline once models are downloaded. NestChat requires OpenRouter API for LLM queries. NestDB and Nestperts work fully offline.

How accurate is NestVision?

Answer: Accuracy varies by image quality and colony density. Typical accuracy is 85-95% for well-lit, overhead images of moderate-density colonies. Use Nestperts to verify and improve results.

Can I add my own data to the database?

Answer: Yes! Use NestDB's Edit Mode to add new rows. Create a checkpoint before bulk additions. Follow existing schema structure.

Is my data secure?

Answer: NestScope runs locally on your machine. No data sent to external servers except LLM API calls for NestChat (query text and results only). NestVision and NestDB are entirely local.

Technical Reference

System Architecture

  • Frontend: Streamlit (port 8501)
  • Backend: FastAPI (port 8000)
  • Expert Tools: Flask (port 5000)
  • Database: SQLite with Git version control
  • CV Framework: ONNX Runtime

Models

  • Detection (Swift): models/swift.onnx (9.6 MB) - Fast inference
  • Detection (Apex): models/apex.onnx (37 MB) - High accuracy
  • Classifier (Swift): models/classifier_swift.onnx (6 MB) - 7-class species groups
  • Classifier (Apex): models/classifier_apex.onnx (21 MB) - 7-class species groups
  • Segmentation: models/mobile_sam.pt (39 MB) - Swift AI for Nestperts

API Endpoints (FastAPI - Port 8000)

  • GET /health - Backend health check
  • GET /config - Backend configuration
  • GET /schema - Database schema
  • POST /ask - NestChat query (non-streaming)
  • POST /ask/stream - NestChat query (streaming)
  • POST /cv/inference - Bird detection on image
  • GET /version/history - Git commit history
  • POST /version/rollback - Rollback to commit

Database Tables

  • tblColonyTotals2010-2021_MayJuneCombined - Main aggregated bird/nest counts
  • tblSpeciesData2010/2011-2013/2015_2018_2021 - Photo record metadata
  • tblColonies - Colony reference data
  • tblSpecies - Species reference data

Configuration Files

  • server/config.yaml - Team-wide configuration (version controlled)
  • .env - Local secrets (NOT version controlled)
