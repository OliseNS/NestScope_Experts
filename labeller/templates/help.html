Frequently Asked Questions

When creating a new project, click "Drop images or click to browse" and your browser will let you select an entire folder. You can upload images alone, or images with existing YOLO label files (.txt) to continue annotation work from another tool.

MobileSAM is an AI segmentation tool that automatically creates bounding boxes when you click on a bird. Press 'A' to activate SAM mode, then simply click on any bird in the image. The AI will detect the bird's outline and create a precise bounding box. This is much faster than manually drawing boxes.

From the project detail page, click "Export" and choose your format: YOLO (for training YOLO models), COCO (standard research format), or GeoJSON (for mapping with geographic coordinates). The export includes all completed annotations and can be filtered by user or date range.

Yes! Nestperts is designed for both experts and non-experts. Non-experts can draw bounding boxes and use AI-assisted species classification, while experts can review and refine the annotations. Assign tasks based on skill level and track progress in real-time.

Nestperts supports JPEG (.jpg, .jpeg) and PNG (.png) formats. For best results with drone imagery, use high-resolution JPEGs. Images are processed locally, so there's no file size limit.

YOLO format (.txt files with normalized coordinates) is designed for training AI models. GeoJSON format includes geographic coordinates (latitude/longitude) and metadata, making it perfect for mapping bird colonies in GIS software or web maps. Use GeoJSON when you need to visualize data spatially.

NestDB provides a Supabase-inspired interface for exploring the bird observation database. Select any table from the left sidebar to view its data. You can click on any cell to edit it inline (press Enter to save, Esc to cancel). Use the search box to filter tables by name. The Data tab shows paginated rows (50 per page), and the Schema tab displays column types and constraints.

In the SQL Editor tab, type what you want to query in plain English (e.g., "Show all birds observed in Texas during 2015"). The AI (Claude Sonnet 4.6) understands the full database schema and generates accurate SQL queries. A confirmation modal shows you the generated SQL before execution. You can review it, then click "Execute Query" to run it. Press Enter or Ctrl+Enter to generate queries quickly.

NestDB automatically tracks all database changes with Git-based version control. Every edit, insert, or query that modifies data is automatically committed. In the Version Control tab, you can view the complete change history, see diffs between versions, create manual checkpoints before major changes, and rollback to any previous state if needed. This ensures you never lose data and can always undo mistakes.

Yes! Click on any cell in the Data tab to edit it. An input field appears where you can modify the value. Press Enter to save changes or Esc to cancel. All changes are tracked in the version control system. Note: Changes are local only and won't affect the actual database unless connected to a write-enabled backend.
