# 🦅 NestScope
## AI-Powered Gulf Coast Bird Conservation Platform

*Transforming complex ecological data into actionable insights through natural language AI*

---

## 🚨 The Problem

### The Environmental Crisis
- **67% of Gulf Coast bird colonies vanished** between 2010-2021
- Direct aftermath of the Deepwater Horizon oil spill disaster
- Critical biodiversity loss across 5 Gulf states

### The Data Accessibility Gap
- Thousands of NOAA observations locked in complex databases
- Researchers spend hours writing SQL queries
- Non-technical conservationists excluded from data-driven decisions
- Time-sensitive conservation efforts delayed by technical barriers

**The Result**: Valuable conservation data sits unused while bird populations continue to decline.

---

## 💡 Our Solution

### NestScope: Two Powerful AI Tools Working Together

#### 🤖 NestChat - Your AI Conservation Assistant
Transform questions into insights in seconds:
- **Natural Language Processing**: Ask questions in plain English
- **Intelligent SQL Generation**: Claude 3.5 Sonnet converts queries automatically
- **Interactive Visualizations**: Dynamic charts, graphs, and maps
- **Real-time Analysis**: Instant population trends and habitat insights

**Example**: *"Show me brown pelican populations in Louisiana from 2015-2020"* → Instant visual analysis

#### 📸 NestVision - AI-Powered Bird Detection
Upload images, get instant species identification:
- **YOLOv6m Computer Vision**: State-of-the-art object detection
- **Multi-Species Recognition**: Trained on Gulf Coast species
- **Automated Counting**: Accurate population estimates from photos
- **Conservation-Ready Data**: Export results for research papers

## 📊 The Data Behind NestScope

### Comprehensive Gulf Coast Coverage
- **13,075+ observations** meticulously catalogued
- **492 distinct bird colonies** tracked over time
- **73 unique species** monitored across the region
- **12 years of data** (2010-2021) capturing post-spill recovery

### Geographic Scope
**Five Gulf States Covered**:
- 🌴 Texas → Coastal wetlands and barrier islands
- 🦐 Louisiana → Mississippi Delta and bayous
- 🏖️ Mississippi → Gulf Islands National Seashore
- ⚓ Alabama → Mobile Bay and coastal preserves
- 🐊 Florida → Panhandle estuaries and beaches

### Data Quality
- Sourced from NOAA's authoritative seabird monitoring program
- Field-verified by professional ornithologists
- GPS-tagged colony locations for mapping precision
- Standardized counting methodologies across all sites

## 🏗️ Technical Architecture

### Modern Full-Stack Platform

**Frontend Layer**
- **Streamlit**: Rapid UI development with Python
- Responsive design for desktop and tablet users
- Real-time chart updates and interactive filtering

**Backend Services**
- **FastAPI**: High-performance async API endpoints
- RESTful architecture for scalability
- Efficient request handling and data validation

**Data Layer**
- **SQLite Database**: 13,000+ records optimized for queries
- Indexed for millisecond-response natural language searches
- Normalized schema for data integrity

**AI/ML Components**
- **Claude 3.5 Sonnet**: Advanced language understanding for query generation
- **YOLOv6m**: 60+ FPS object detection for real-time bird identification
- Custom-trained model weights for Gulf Coast species

**Deployment**
- Containerized with Docker for reproducibility
- Environment-based configuration for dev/prod
- Ready for cloud deployment (AWS, GCP, Azure)
