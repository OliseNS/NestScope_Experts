PROJECT OVERVIEW
--------------------------------------------------------------------------------
NestScope uses AI to make 49,224 NOAA bird observation records instantly
accessible through natural language—no SQL expertise required. Addresses the
Gulf Coast biodiversity crisis where 67% of colonies vanished (2010-2021)
following the Deepwater Horizon oil spill.


THE PROBLEM
--------------------------------------------------------------------------------
Environmental Crisis:
- 194 of 288 bird colonies lost between 2010-2021 (67% decline)
- Critical biodiversity loss across Texas, Louisiana, Mississippi, Alabama,
  and Florida
- Post-Deepwater Horizon recovery monitoring essential

Data Accessibility Gap:
- Thousands of NOAA observations locked in complex databases
- Requires SQL expertise and hours of query development
- Excludes non-technical conservationists from decision-making
- Delays urgent conservation efforts


THE SOLUTION
--------------------------------------------------------------------------------
Two AI-Powered Systems:

1. NESTCHAT - Natural Language Database Interface
   - Ask questions in plain English: "How many brown pelicans in Louisiana?"
   - Claude Opus 4.5 automatically generates optimized SQL queries
   - Interactive charts (Plotly) and geographic maps (Folium)
   - Real-time streaming responses with progress indicators
   - CSV export for further analysis

2. NESTVISION - Computer Vision Bird Detection
   - Upload colony photos for instant species identification
   - YOLOv6m object detection (60+ FPS)
   - Automated population counting with confidence scores
   - Bounding box visualization on detected birds


TECHNICAL ARCHITECTURE
--------------------------------------------------------------------------------
Frontend:      Streamlit with custom dark theme, interactive visualizations
Backend:       FastAPI with Server-Sent Events for real-time streaming
Database:      SQLite (49,224 records across 7 optimized tables)
AI/LLM:        Claude Opus 4.5 for text-to-SQL generation
Computer Vision: YOLOv6m for bird detection
Engineering:   487-line engineered prompt with domain-specific query patterns

Key Innovation: Context-aware SQL generation distinguishes between counting
observation records (49,224) vs counting birds/nests (5,931), with mandatory
coordinate inclusion for geographic visualization.

INSTALLATION
--------------------------------------------------------------------------------
# Clone repository
git clone https://github.com/OliseNS/nexus_project
cd nexus_project

# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate   # Windows

# Install dependencies
pip install -r requirements.txt

# Configure API key
echo "OPENROUTER_API_KEY=your_key_here" > .env

# Start backend (Terminal 1)
uvicorn server.main:app --reload --port 8000

# Start frontend (Terminal 2)
streamlit run frontend/app/app_ui.py

# Access application at http://localhost:8501


TECHNICAL DIFFERENTIATORS
--------------------------------------------------------------------------------
1. Engineered Prompt System - 487-line prompt with 6 query patterns and
   mandatory coordinate rules for geographic visualization

2. Streaming Architecture - FastAPI + Server-Sent Events for responsive UX
   on long-running queries

3. Intelligent Data Routing - Automatic table selection between detailed
   observation records vs aggregated summaries

4. Production Error Handling - Prevents duplicate chart IDs, graceful
   failures, user-friendly error messages

5. Domain Expertise - Built specifically for ornithological research workflows
   with species validation and year range enforcement
