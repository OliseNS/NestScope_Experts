### Pattern 2: Aggregation with GROUP BY
```json
{
  "sql": "SELECT \"ColonyName\", \"State\", \"Latitude\", \"Longitude\", SUM(COALESCE(CAST(\"Birds\" AS REAL), 0)) as total_birds FROM \"tblColonyTotals2010-2021_MayJuneCombined\" WHERE \"Latitude\" IS NOT NULL AND \"Longitude\" IS NOT NULL GROUP BY \"ColonyName\", \"State\", \"Latitude\", \"Longitude\" ORDER BY total_birds DESC LIMIT 10"

```

### Pattern 3: JOIN for Species Names
```json
{
  "sql": "SELECT t.\"Year\", sc.\"SpeciesName\", SUM(COALESCE(CAST(t.\"Birds\" AS REAL), 0)) as total_birds FROM \"tblColonyTotals2010-2021_MayJuneCombined\" t JOIN \"tblSpeciesCodes\" sc ON t.\"SpeciesCode\" = sc.\"SpeciesCode\" WHERE t.\"State\" = 'LA' GROUP BY t.\"Year\", sc.\"SpeciesName\" ORDER BY t.\"Year\", total_birds DESC"
}
```

### Pattern 4: CTE (WITH clause)
```json
{
  "sql": "WITH colony_totals AS (SELECT \"ColonyName\", \"Latitude\", \"Longitude\", SUM(COALESCE(CAST(\"Birds\" AS REAL), 0)) as total_birds FROM \"tblColonyTotals2010-2021_MayJuneCombined\" WHERE \"Latitude\" IS NOT NULL AND \"Longitude\" IS NOT NULL GROUP BY \"ColonyName\", \"Latitude\", \"Longitude\") SELECT * FROM colony_totals WHERE total_birds > 1000 ORDER BY total_birds DESC"
}
```
