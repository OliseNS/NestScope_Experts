# DATABASE SCHEMA

## Table: species_codes
Lookup table for species identification codes.

Columns:
- SpeciesCode (TEXT): 4-letter species code (e.g., "BRPE", "LAGU", "SATE")
- SpeciesName (TEXT): Full species name (e.g., "Brown Pelican", "Laughing Gull", "Sandwich Tern")

Common Species Codes:
- BRPE = Brown Pelican
- LAGU = Laughing Gull
- SATE = Sandwich Tern
- ROYT = Royal Tern
- WHIB = White Ibis
- GREG = Great Egret
- TRHE = Tricolored Heron
- SNEG = Snowy Egret
- BLSK = Black Skimmer
- GBTE = Gull-billed Tern
- FOTE = Forster's Tern
- CATE = Caspian Tern
- ROSP = Roseate Spoonbill
- GBHE = Great Blue Heron
- DCCO = Double-crested Cormorant

Special/Aggregate Codes:
- UNWA = Unknown Waterbird (likely in proportion of species present)
- UNTE = Unknown Tern species
- UNGU = Unknown Gull
- WHEG = Great/Snowy Egret (White Egret - when distinction unclear)
- DAIB = Glossy/White-faced Ibis (Dark Ibis)
- ROSA = Royal or Sandwich Tern
- ALL = All breeding species at colony

## Table: colony_coordinates
Geographic reference data for colony locations in the Chandeleur Islands area.

Columns:
- ColonyID (TEXT): Unique identifier (e.g., "CIN_2010_A", "CIS_2015_B")
- ActiveInventory (TEXT): "Yes" if currently active, blank otherwise
- ColonyGroupBuffer (TEXT): Broader geographic grouping
- ColonyName (TEXT): Specific colony name
- State (TEXT): State code (LA, MS, AL, FL, TX)
- Year_ChandeleursOnly (REAL): Year (specific to Chandeleur Islands)
- Longitude (REAL): Longitude in decimal degrees (negative = West)
- Latitude (REAL): Latitude in decimal degrees
- GeoRegion (TEXT): Geographic region
- ExtrapArea (TEXT): Extrapolation area classification
- TerrestEcoRegion (TEXT): Terrestrial ecoregion
- MarineEcoRegion (TEXT): Marine ecoregion
- FormerNames (TEXT): Historical names for this colony
- OrigDotterID (TEXT): Original survey ID code
- NOTES August 2022 (TEXT): Recent notes
- Colony Years Within 500 m (TEXT): Related colonies within 500m

## Table: colony_inventory
Comprehensive inventory of all surveyed colonies with metadata.

Columns:
- ID (REAL): Record identifier
- Latitude (REAL): Latitude in decimal degrees

- Dotter (TEXT): Observer initials (e.g., "PJC", "KKN", "MWP", "SLF")

- ColonyName (TEXT): Colony name
- Habitat (TEXT): Habitat description (free-form text)
- Oil (TEXT): Oil presence indicator ("Y" = Yes, "N" = No)
- Notes (TEXT): Field observations and notes

Important: Habitat descriptions are free-form and may include terms like:
- "marsh/grass island"
- "sand", "sandy", "beach"
- "shrubs", "trees", "mangrove island"
- "barrier island"
- "intertidal"

## Table: colony_site_notes
Survey notes and metadata for each colony visit (2010-2021 combined).

Columns:
- Year (REAL): Survey year
- Date (TIMESTAMP): Survey date (datetime format)
- ColonyName (TEXT): Colony name
- Dotter (TEXT): Observer initials
- Dotter'sColonyNumber (TEXT): Observer's colony numbering system
- Habitat (TEXT): Habitat description
- Oil (TEXT): Oil presence ("Y"/"N")
- SpeciesCode (TEXT): Species code (may be blank if no birds observed)

# QUERY GUIDELINES

## Understanding the Data Structure

1. **Multiple Species Tables**: Bird observations are split across three tables by year range:
   - species_data_2010 (year 2010 only)
   - species_data_2011_2013 (years 2011-2013)
   - species_data_2015_2021 (years 2015, 2018, 2021)

   When querying across years, use UNION to combine results from multiple tables.

2. **Different Detail Levels**:
   - colony_totals = Aggregated summary data (faster for counts)
   - species_data_* = Detailed observation data (more granular)

3. **Coordinate Precision**:
   - Stored as REAL numbers
   - Valid range: Latitude 24-31°N, Longitude -98 to -80°W
   - Some records may have NULL coordinates

4. **Date Formats**:
   - Stored as TEXT in ISO format or MM/DD/YY format
   - Use strftime() for date operations
   - Extract year: CAST(strftime('%Y', Date) AS INTEGER)

5. **Null Handling**:
   - Many numeric fields may be NULL or 0
   - Text fields may be blank strings or NULL
   - Always use IS NULL or IS NOT NULL for null checks
   - Use COALESCE() for default values

## Common Query Patterns

### Pattern 1: Species Counts by Year
```sql
-- Use colony_totals for aggregated data
SELECT Year, SpeciesCode, SUM(Nests) as total_nests, SUM(Birds) as total_birds
FROM colony_totals
WHERE SpeciesCode = 'BRPE'
GROUP BY Year, SpeciesCode
ORDER BY Year;
```

### Pattern 2: Colony-Specific Information
```sql
-- Get all observations for a specific colony
SELECT Year, SpeciesCode, Nests, Birds, Notes
FROM colony_totals
WHERE ColonyName = 'Breton Island'
ORDER BY Year;
```

### Pattern 3: Geographic Queries
```sql
-- Find colonies in a geographic region
SELECT DISTINCT ColonyName, State, GeoRegion
FROM colony_totals
WHERE State = 'LA' AND GeoRegion LIKE '%Chandeleur%'
ORDER BY ColonyName;
```

### Pattern 4: Species Lookup with Join
```sql
-- Join with species codes for full names
SELECT ct.Year, sc.SpeciesName, SUM(ct.Nests) as total_nests
FROM colony_totals ct
JOIN species_codes sc ON ct.SpeciesCode = sc.SpeciesCode
WHERE ct.Year = 2021
GROUP BY ct.Year, sc.SpeciesName
ORDER BY total_nests DESC;
```

### Pattern 5: Multi-Year Species Data (UNION)
```sql
-- Query across all species observation tables
SELECT Year, ColonyName, SpeciesCode, WBN, Site, Notes
FROM species_data_2010
WHERE SpeciesCode = 'LAGU'

UNION ALL

SELECT Year, ColonyName, SpeciesCode, WBN, Site, Notes
FROM species_data_2011_2013
WHERE SpeciesCode = 'LAGU'

UNION ALL

SELECT Year, ColonyName, SpeciesCode, WBN, Site, Notes
FROM species_data_2015_2021
WHERE SpeciesCode = 'LAGU'

ORDER BY Year, ColonyName;
```

### Pattern 6: Handling Empty Results
```sql
-- Always check for NULL/empty conditions
SELECT ColonyName, COUNT(*) as observation_count
FROM colony_site_notes
WHERE Oil = 'Y'
GROUP BY ColonyName;

-- If this returns no rows, the query succeeded but found no oil observations
-- NOT an error - just no matching data
```

### Pattern 7: Detailed Observation Data
```sql
-- Get detailed nest/brood counts from species_data tables
SELECT
    ColonyName,
    SpeciesCode,
    SUM(COALESCE(WBN, 0)) as with_brood_on_nest,
    SUM(COALESCE(ChickNest, 0)) as chick_nests,
    SUM(COALESCE(Site, 0)) as total_sites,
    SUM(COALESCE(EmptyNest, 0)) as empty_nests
FROM species_data_2021
WHERE Year = 2021
GROUP BY ColonyName, SpeciesCode
ORDER BY total_sites DESC;
```

### Pattern 8: Text Search in Notes
```sql
-- Search for keywords in observation notes
SELECT ColonyName, Year, SpeciesCode, Notes
FROM colony_totals
WHERE Notes LIKE '%oil%' OR Notes LIKE '%boom%'
ORDER BY Year;
```

### 5. Column Name Handling
Be aware of schema differences:
- species_data_2010: Uses "ChickNestw/outAdult" only
- species_data_2011_2013: Adds "ChickNest" column
- species_data_2015_2021: Adds "Territory" and "Subcolony"

When querying across tables, only use columns that exist in all tables, or use NULL for missing columns:

```sql
SELECT
    Year, ColonyName, SpeciesCode, WBN, Site,
    NULL as Territory  -- Not in 2010-2013 data
FROM species_data_2010
UNION ALL
SELECT Year, ColonyName, SpeciesCode, WBN, Site, Territory
FROM species_data_2015_2021;
```

### 6. Handle Numeric vs Text Carefully
- Year: Stored as REAL, cast to INTEGER for display
- Counts (Nests, Birds, WBN, etc.): Stored as REAL, may be NULL
- Dates: Stored as TEXT
- Coordinates: Stored as REAL

Always use COALESCE() for numeric fields that may be NULL:
```sql
SUM(COALESCE(Nests, 0))  -- Treats NULL as 0
```

### 7. Performance Optimization
- Use indexes: Tables have indexes on Year, ColonyName, SpeciesCode, State
- Use LIMIT when showing examples
- Prefer colony_totals for simple aggregations (faster than species_data_*)
- Use specific year tables rather than UNION when possible

**Ambiguous colony name:**
User: "Show me Deer Island data"
Response: "I found multiple colonies with 'Deer' in the name: 'Deer Island Northeast', 'North Deer Island', 'South Deer Island'. Which one would you like?"

## Special Considerations

### Oil Presence
Oil field = "Y" indicates confirmed oil presence (likely from Deepwater Horizon spill 2010).
Colonies with oil observations are particularly notable for research.

### Observer Codes (Dotter)
Common observers: PJC, KKN, MWP, SLF, WAW, RSW, EAM, PAG, KMR, DLJ
Different observers may have different coverage or methodology.

### Photo Quality (PQ)
- "E" (Excellent): High confidence in counts
- "G" (Good): Reasonable confidence
- "P" (Poor): Lower confidence, estimates may be less accurate

### Best Estimate Flag (BestForBPE)
"Y" indicates this record represents the best population estimate for that colony/species/year.
Use this flag when you need the most reliable data.
