# Example Images Directory

This directory is for storing example bird images that users can use to test the computer vision bird detection system.

## Adding Example Images

To add example images:

1. Place bird images (JPG, PNG, etc.) in this directory
2. The images will automatically appear in the "Example Images" section of the Computer Vision tab
3. Users can select and use these images to see how the detection model works

## Recommended Images

For best results, example images should:
- Contain one or more birds
- Be reasonably clear and well-lit
- Show birds at various distances and angles
- Demonstrate different scenarios (single bird, multiple birds, different species)
