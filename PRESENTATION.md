# NestScope
AI-Powered Gulf Coast Bird Conservation Platform

---

## Problem
67% of Gulf Coast bird colonies disappeared (2010-2021) post-Deepwater Horizon. Complex NOAA data inaccessible to non-experts.

---

## Solution
**NestChat**: Natural language → SQL queries → Interactive charts/maps
**NestVision**: Image upload → YOLOv6m detection → Bird counting

---

## Data
13,075+ observations, 492 colonies, 73 species (2010-2021)
Gulf Coast: TX, LA, MS, AL, FL

---

## Stack
Streamlit + FastAPI + SQLite + Claude 3.5 Sonnet + YOLOv6m

---

## Features
Natural language queries • Interactive visualizations • Bird detection • Real-time streaming • CSV export

---

## Impact
Researchers: population analysis • Conservationists: habitat monitoring • Policymakers: evidence-based decisions • Educators: data science teaching

---

## Conclusion
Making conservation data accessible through AI for faster insights and action.
